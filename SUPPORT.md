# Support

Use GitHub issues for reproducible bug reports, installation problems, documentation gaps, and feature requests:

https://github.com/castrattonDSU/FibrTraQ/issues

For a useful report, include:

- FibrTraQ version or commit SHA;
- operating system and R version;
- the command or script that failed;
- the manifest, if using `ftq_run()`;
- the exact error message;
- whether the issue appears with a small test tractogram or only with a large dataset.

Do not include private health information, unpublished human-subject data, API tokens, or other sensitive files in public issues.
