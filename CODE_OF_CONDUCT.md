# Code of Conduct

FibrTraQ follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project respectful and harassment-free for everyone, regardless of background, identity, experience level, or role in the project.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and receive constructive feedback professionally.
- Focus criticism on ideas, code, documentation, and scientific interpretation, not people.

## Unacceptable Behavior

Harassment, insults, threats, discriminatory language, sustained disruption, and unwanted personal attention are not acceptable in this project.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this code of conduct. Serious or repeated violations may result in temporary or permanent bans from project spaces.

## Reporting

Report concerns to the package maintainer listed in `DESCRIPTION`. Reports will be handled with appropriate confidentiality and care.
